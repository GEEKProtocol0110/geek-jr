# Geek Jr Security

## Current status

Geek Protocol is Public Alpha and has not completed an independent security audit.

Geek Jr is a family early-learning product. Do not request or store children's personal information. Never ask for wallet seeds or private keys.

Preferences, learner nicknames, and parent observations stay in this browser. There is no account system. The optional learning-reward plan is a local draft and does not create a token balance, claim, or payout. See [privacy and storage](docs/PRIVACY.md).

Project-wide policy is in [Geek Protocol HQ's SECURITY.md](https://github.com/GEEKProtocol0110/geek-protocol-hq/blob/main/SECURITY.md). Mint, wallet, and settlement rules in that document describe HQ. They do not describe this learning site.

## Reporting a vulnerability

Private vulnerability reporting is enabled on this repository. Use GitHub private vulnerability reporting. Do not open a public issue.

Include:

- the affected commit and environment;
- reproducible steps or a proof of concept;
- expected and observed behavior; and
- impact to families, content integrity, or availability.

Stop after the smallest demonstration that explains the issue. Do not access another person's data, degrade the site, or submit malware.
